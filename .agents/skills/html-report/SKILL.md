# /html-report - Job Search Funnel Dashboard

Generates a standalone, dependency-free HTML report visualizing your application pipeline from `job_search_tracker.csv`.
- KPI cards (Applications submitted, Interviews scheduled, Offers received, Response rate)
- Visual SVG funnel chart and status distribution
- Interactive, searchable applications table
